# options-lab

期权入门交互课，从零讲起，用真实的 TSLA 期权报价和价格路径。

An introductory interactive options course. It starts from zero and uses real TSLA option quotes and price paths.

在线访问 / Live site: https://luoy2.github.io/options-lab/

页面按浏览器的默认语言显示中文或英文；网址后加 `?lang=zh` 或 `?lang=en` 可以指定语言。

Pages show Chinese or English according to the browser's default language. Add `?lang=zh` or `?lang=en` to a URL to choose the language.
