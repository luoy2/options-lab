box · roll · collar

5.2 在一个行权价上用 parity 把 call、put 和股票拴在一起：conversion 到期按行权价卖掉股票，价格里只剩利息。这一节把两组合成股票拼起来：两个行权价拼成 box，价格里只剩利率；两个到期日拼成 roll，只剩两个到期日之间的持有成本。第三样 collar 不是套利：拿着股票，卖 call 收来的钱拿去买 put。案例还是 2026-04-13 收盘的 TSLA 期权链。

〇一张期权贵不贵

讲义 Session 7 开头问：12 月到期的 100 call 卖 8.75，便宜还是贵？只看这一张，答不出来。

讲义接着给了两种情况。讲义没给利率，下面按不计利息算。

同时还能做的交易组合到期至少赚结论
按 110 卖出标的买 100 call 付 8.75，卖空标的收 1101.25和标的比，这张 call 太便宜
按 3.25 买 105 call卖 100 call 收 8.75，买 105 call 付 3.250.50和 105 call 比，这张 call 太贵

第一种：到期时标的在 100 上方，行权 call，按 100 买回标的还掉，110 − 100 − 8.75 ＝ 1.25；在 100 下方，直接按市价买回，买得比 100 还便宜，赚得更多。第二种：两张 call 一卖一买，今天净收 5.50；到期时这组价差最多要赔两个行权价之差 5，至少剩 0.50。

同一个 8.75，和标的比太便宜，和 105 call 比又太贵。期权的价格只有放在别的合约旁边才能判断高低，这叫相对价值。讲义的原话是：交易员说自己在交易理论价值，很多时候其实是在交易相对价值。

拴住期权价格的几种关系

5.2 的 conversion 是一种：同一个行权价上的 call、put 和股票，三者的差价只能是利息和分红。这一节再加三种。它们都用到合成股票：

结构腿到期时发生什么价格里剩下什么
conversion（5.2）买股票、卖 call、买 put，同一行权价按行权价卖掉股票利息、分红
box低行权价买合成股票，高行权价卖合成股票，同一到期日低价买进、高价卖出，拿到两个行权价之差利息
roll近月卖合成股票，远月买合成股票，同一行权价近月按行权价卖出，远月按行权价买回两个到期日之间的利息减分红
collar拿着股票，买 put、卖 call卖出价被夹在两个行权价之间不是套利：卖 call 的钱付 put

前三种的到期结果和标的走到哪里无关，价格里只剩利率和分红。反过来，它们的市价就能告诉你市场在用多少利率；市价一旦偏离该值，就能卖贵的一边、买便宜的一边，锁定中间的差价。

四条腿换一种分组：买 300 call、卖 400 call 是 3.1 的牛市 call 价差（bull call spread），今天中间价 52.20；买 400 put、卖 300 put 是熊市 put 价差（bear put spread），47.775。box 就是这两个垂直价差之和。TSLA 涨的时候 call spread 值钱，跌的时候 put spread 值钱，一个多出多少，另一个就少多少，合计不变。

box ＝ (X高 − X低) ÷ (1 ＋ r·t)
到期固定拿到两个行权价之差，今天的价值是把这笔钱按利率折回今天

买 box：今天付一笔钱，到期拿回一笔固定的钱，和把钱存进银行、借给别人是同一件事。卖 box：今天收钱，到期付出固定的一笔，就是借钱。所以 box 的价格就是一个利率。

讲义的数字。100/110 box，离到期 10 周，利率 5.25%：10 ÷ (1 ＋ 5.25% × 10/52) ＝ 9.90。box ＝ call spread ＋ put spread，所以已知其中一个就能推另一个：100/110 call spread 报 5.25，put spread 该是 9.90 − 5.25 ＝ 4.65；put spread 报 7.40，call spread 该是 2.50。练习题：70/80，52 天，利率 4.24%，box ＝ 10 ÷ (1 ＋ 4.24% × 52/365) ＝ 9.94；put spread 报 6.30，call spread 该是 9.94 − 6.30 ＝ 3.64。

5.1 那个 325/350 box，4/13 收盘中间价 24.95；按 1.1 反解的利率 4.3%，该值 25 ÷ (1 ＋ 4.3% × 32/365) ＝ 24.91。把式子倒过来，从 box 的价格就能反推利率：

r ＝ [(X高 − X低) ÷ box − 1] ÷ t
到期拿到的钱比今天付的钱多出的比例，是这段时间的利率；再除以年数，换成年利率

二用 TSLA 的 box 反推利率

1.1 用股价和一对 call、put 反解利率，340 到 360 几档在 4.1% 到 4.4%。box 不用股价，只用四个期权价。

300/400 这个 box，4/13 收盘中间价 99.975。代进上面的式子：(100 ÷ 99.975 − 1) ÷ (32/365) ＝ 0.29%。按 4.3% 它应该值 100 ÷ (1 ＋ 4.3% × 32/365) ＝ 99.62，市价高了 0.35，反推的利率就比 4.3% 低得多。原因有两个。

原因一：四个中间价，各有几分钱误差

100 块放 32 天，按 4.3% 的利息只有 0.38。box 要从四个价格里把这 0.38 量出来，每个价格差几分钱，利率就差很多：300/350 这个 box 的价格差 1 分钱，反推的利率就差 0.23 个百分点。4/13 这一天 ORATS 有 242 个分钟快照，逐个算 300/350 这个 box：反推的利率中位数 2.86%，一半的时候落在 1.71% 到 3.43% 之间，最低 −7.37%，最高 13.85%。

原因二：美式 put 可以提前行权

box 的式子默认期权只能在到期日行权，这叫欧式。TSLA 的期权是美式，到期前哪天都能行权。400 put 是实值（行权价 400 高于股价 352.36），买方可以提前行权，早点按 400 卖出股票，拿到现金去生息（5.2 第四节提过，节点 9 专门讲）。这个权利值钱，所以美式的 400 put 比式子里的欧式价格贵。用 5.2 第四节的二叉树模型（把 32 天切成 2000 小步，每步 TSLA 涨一格或跌一格，从到期往回算；美式 put 每一步比较现在行权和继续拿着哪个值钱），按 4.3% 的利率算，这部分值 0.37；300 put 是虚值，只值 0.01。这两个数叫提前行权价值。

box 里买的是 400 put、卖的是 300 put，box 就多付了 0.37 − 0.01 ＝ 0.36，价格被抬高，反推的利率偏低。扣掉这 0.36，box 是 99.61，反推 4.41%，回到 1.1 的范围附近。

按中间价反推 扣掉提前行权价值后 1.1 用股价反解的 4.10% 到 4.43% 竖点线：股价 352.36，右边那张 put 是实值

上限在股价左边时，两张 put 都是虚值，提前行权价值只有几分钱，点在 2% 到 5% 之间跳，那是报价误差。上限过了股价，那张 put 越来越实值，提前行权价值越来越大，原始的点就一路往下掉。扣掉模型算的提前行权价值，点又回到 4% 上下。

模型算提前行权价值时要用一个利率，这里用 4.3%。所以扣完得到 4.41%，说明 4.3% 和这些报价不矛盾，但不是单靠 box 独立量出来的：模型里改用 3%，扣完是 2.92%。1.1 用股价反解的那几档也含一点这种影响，那几档 put 在平值附近，影响小一些。

按能成交的价格

中间价成交不了。真要买这个 box，300 call 和 400 put 得按卖一买、400 call 和 300 put 得按买一卖，一共付 100.65，比到期拿到的 100 还多，反推的利率是 −7.37%。反过来卖这个 box，只收 99.30，相当于按 8.04% 借钱。四条腿的买卖价差合计 1.35，是 32 天利息 0.38 的 3.6 倍。

所以拿个股期权的 box 借钱或放钱，价差会吃掉全部利息。市场上用 box 借贷，用的是欧式的指数期权：没有提前行权，期限也长得多，利息相对价差大得多。

三roll：两个到期日

box 固定到期日、换行权价；roll 固定行权价、换到期日。行业里也叫 jelly roll。

同一个行权价 X，两个到期日：近月 t1、远月 t2。买入一个 roll：

  • 近月卖合成股票：卖近月 call，买近月 put。近月到期时按 X 卖出股票。
  • 远月买合成股票：买远月 call，卖远月 put。远月到期时按 X 买回股票。

近月按 X 卖出，远月按 X 买回，股票一出一进抵消。剩下的是两个到期日之间这段时间：手里多了 X 的现金，可以生息；手里少了股票，这段时间的分红拿不到。所以 roll 的价值就是这段时间 X 的利息减去分红，叫持有成本。TSLA 往哪走、隐含波动率怎么变，都不影响它：合成股票的价格 C − P 由 parity 定死（5.2），里面没有波动率。这对欧式期权成立；美式 put 带着提前行权价值，会带进一点波动率，第二节讲过。

写成式子：买入 roll，近月到期时按 X 卖出股票，收到 X；远月到期时按 X 买回，付出 X。两笔钱各自按利率折回今天再相减，就是下面的第一个式子。r·t 很小时，它约等于 X 在 t2 − t1 这段时间的利息 X·r·(t2 − t1)。

roll ＝ X ÷ (1 ＋ r·t1) − X ÷ (1 ＋ r·t2) − D ≈ X·r·(t2 − t1) − D
近月收到的 X 的现值，减远月付出的 X 的现值，再减这段时间拿不到的分红
roll ＝ (C远 − P远) − (C近 − P近) ＝ call calendar − put calendar
远月的 C − P 减近月的 C − P。同一行权价的 C − P 叫 combo（5.2），就是合成股票的价格。重新分组，就是买 call calendar（3.2）、卖 put calendar

box 是 call spread 加 put spread，roll 是 call calendar 减 put calendar。讲义特意把两者并排放，因为这个符号容易记反：box 的两个价差都是买入，roll 的两个 calendar 一买一卖。

讲义的数字。80 roll，近月 2 个月、远月 5 个月，利率 6%，两个到期日之间分红 0.47。精确：80 ÷ (1 ＋ 6% × 2/12) − 80 ÷ (1 ＋ 6% × 5/12) − 0.47 ＝ 0.69；近似：80 × 6% × 3/12 − 0.47 ＝ 0.73。t 用的是两个到期日之间的 3 个月，不是到远月的 5 个月。call calendar 报 3.25，put calendar 该是 3.25 − 0.69 ＝ 2.56。练习题：70 roll，17 天与 80 天，利率 3.89%，分红 0.11：70 × 3.89% × 63/365 − 0.11 ＝ 0.36；call calendar 报 2.45，put calendar 该是 2.09。

分红大过利息，也就是 D ＞ X·r·(t2 − t1) 时，roll 是负的：put calendar 比 call calendar 贵。TSLA 不派息，roll 总是正的。

讲义例题：天然的空头。一家七月要买进某种商品的用户，价格涨了就吃亏，相当于天然持有空头。七月期货 1914；七月 1950 call 53，1850 put 41。只买 1950 call：成本最高 1950 ＋ 53 ＝ 2003，价格跌了照样享受。只卖 1850 put：成本最低 1850 − 41 ＝ 1809，涨了没有保护。买 1950 call、卖 1850 put：七月价格高于 1950 时成本 1962，低于 1850 时 1862，中间是市价加 12。这是空头的 collar：买 call 当保险，卖 put 收租，净付 12。

五补齐一张缺价格的报价表

报价表里的价格互相拴着。只要有两个行权价上 call 和 put 都齐全，利率和股价就定了，缺的格子都能补出来。

①
r ＝ [(X高 − X低) ÷ box − 1] ÷ t
用两个齐全的行权价拼一个 box，反推利率（第一节）
②
S ＝ C − P ＋ X ÷ (1 ＋ r·t)
在其中一个齐全的行权价上用 parity 反推股价（5.2；TSLA 不派息）
③
C ＝ P ＋ S − X ÷ (1 ＋ r·t)
P ＝ C − S ＋ X ÷ (1 ＋ r·t)
缺 call 就用同一行权价的 put 补，缺 put 就用 call 补

六相对价值套利

conversion、box、roll 都有一个由利率和分红定死的该值。市价偏离该值，就卖贵的一边、买便宜的一边，锁定差价，不用猜方向。

讲义 Session 7 的例子市价该值做法锁定

还剩哪些风险

  • 利率和分红变了。roll 的价值就是利息减分红；conversion、reversal 也一样（5.2）。
  • 美式期权被提前行权。卖出的实值 put 可能被提前指派，box 或 roll 就少了一条腿（节点 9）。
  • 到期停在行权价上。不知道自己卖出的那张会不会被指派，是 5.2 的 pin risk。box 有两个行权价，roll 的近月腿先到期，都会碰到。
  • 买卖价差。第二节 TSLA 的 box，四条腿的价差 1.35 是利息的 3.6 倍。

七费曼检验

七道题都不用计算器。先用自己的话写下来，再展开对照，看自己的解释缺了哪一步。

答案只存在本机浏览器里。

本页出现的全部符号与术语
相对价值
一个价格相对于别的价格是高是低。做相对价值交易，赚的是几个价格之间的关系被打破的那一点。
合成股票
同一行权价、同一到期日，买 call、卖 put 到期一定按行权价买到股票（合成多头）；卖 call、买 put 一定按行权价卖出（合成空头）。5.1。
卖空
借来标的卖掉，以后再买回来还给借出方。
box
低行权价买合成股票、高行权价卖合成股票，同一到期日。到期固定拿到两个行权价之差，价格里只剩利率。＝ call spread ＋ put spread。
call spread / put spread
同一种期权、两个行权价一买一卖（3.1）。box 里是买低卖高的 call spread 和买高卖低的 put spread。
roll（jelly roll）
同一行权价，近月卖合成股票、远月买合成股票。价值是两个到期日之间的持有成本。＝ call calendar − put calendar。
calendar
同一行权价、两个到期日，买远月、卖近月（3.2）。
combo
同一行权价、同一到期日的 C − P，合成股票的价格（5.2）。
持有成本
持有标的一段时间的净成本：买它的钱的利息，减去这段时间的分红。
collar
拿着股票，买低行权价 put、卖高行权价 call。股票到期的价值被夹在两个行权价之间；多头的 collar 到期形状和牛市价差一样，只多一笔固定的现金，所以讲义写 collar ≈ bull spread。
protective put
拿着股票再买 put，亏损有底，付权利金。
covered call
拿着股票再卖 call，先收钱，涨过行权价的部分让出去。
欧式 / 美式
欧式只能在到期日行权；美式到期前任何一天都能行权。美国个股期权是美式。
实值 / 虚值
现在行权就值钱的叫实值，不值钱的叫虚值（2.1）。put 的行权价高于股价是实值，call 的行权价低于股价是实值。
提前行权价值
美式期权比同样条件的欧式期权多出的价值。本页用 CRR 二叉树模型算，是模型值。
二叉树模型
把到期前的时间切成很多小步，每步股价涨一格或跌一格，从到期往回算期权今天的价值；美式 put 每一步比较现在行权和继续拿着，取大的（5.2 第四节）。
parity（put-call parity）
同一行权价、同一到期日：C − P ＝ S − X ÷ (1 ＋ r·t)，有分红再减分红（5.2）。按欧式期权推导。
conversion / reversal
买股票、卖 call、买 put，到期一定按 X 卖出股票 / 反过来卖空股票、买 call、卖 put，到期一定按 X 买回（5.2）。
Black-Scholes
用股价、行权价、利率、到期时间和波动率算期权价格的公式（2.1）。本页只在第四节用它拆开 collar 两边不对称的原因。
远期价
今天约定、到期交割的价格。不派息时等于股价加上到期前的利息：352.36 × (1 ＋ 4.3% × 32/365) ＝ 353.69（1.1）。
隐含波动率
从期权的市场价格反推出的波动率（1.2）。本页的二叉树用 ORATS 给每个行权价算的值。
标准差
一组数离平均值的典型距离（1.2）。
指派 / pin risk
卖出期权的一方被对手行权选中，必须履约 / 到期时股价停在行权价附近，不知道自己卖出的那张会不会被指派（5.2）。
中间价 / 买一 / 卖一
买一是有人愿意买的最高价，卖一是有人愿意卖的最低价，中间价是两者的平均。自己买按卖一成交，卖按买一成交。
X
行权价。
X高, X低
box 的两个行权价。
C / P
同一行权价、同一到期日的 call 价格 / put 价格。roll 里 C远、P远 是远月的，C近、P近 是近月的。
S
今天的股价。
r
年利率，单利。1.1 从 TSLA 的 parity 反解出约 4.3%。
t, t1, t2
到期时间，以年计。roll 里 t1 是近月、t2 是远月，利息算的是两者之间那一段。
D
分红。roll 里是两个到期日之间的分红。TSLA 不派息。
skew
同一到期日、不同行权价的隐含波动率不一样。节点 8。
